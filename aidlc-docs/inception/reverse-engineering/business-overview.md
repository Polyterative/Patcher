# Business Overview

## Business Context
Patcher is a digital twin workspace for Eurorack musicians. It helps users document patches, plan racks, track modules, and keep public hardware data in sync.

## Business Transactions
- Create and edit patch records
- Browse public and private patch details
- Plan racks and analyze HP, power, and balance
- Browse the module database
- Manage user accounts, profiles, and auth flows
- Publish and browse comments, tags, and discovery metadata

## Component-Level Business Descriptions
### Patch Browsing
Supports patch lists, patch details, graphs, privacy, and comments.

### Rack Browsing
Supports rack lists, rack details, layout planning, and balance analysis.

### Module Browsing
Supports module discovery, filtering, module details, and module relationships.

### Backbone / Shell
Provides home, auth, account, SEO, alerts, footer, and shared shell behavior.

### Admin / Backend
Provides admin-only views and backend management entry points.
