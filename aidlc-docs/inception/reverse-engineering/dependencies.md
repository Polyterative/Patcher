# Dependencies

## Internal Dependencies
- App shell depends on backbone and feature modules
- Feature browsers depend on component packages and shared interproject utilities
- Component packages depend on data services and shared atoms
- Backend layer depends on generated types and environment configuration

## External Dependencies
- `@angular/*` - application framework
- `@angular/material` - UI library
- `@supabase/supabase-js` - backend client
- `rxjs` - reactive flow
- `@sentry/*` - error monitoring
- `ngx-timeago`, `luxon-angular` - date/time display
